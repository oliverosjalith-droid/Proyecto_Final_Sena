# Ejercicio orientado a objetos

Un **ejercicio orientado a objetos** en programación es una práctica que te pide resolver un problema usando el paradigma de la [Programación Orientada a Objetos (POO)] organizando el código en **clases** y **objetos** en lugar de usar solo funciones o listas de instrucciones sueltas.

## Ejemplos

## 1.  ejercicio en visual basic

Sub programa()
   A = InputBox("¿cuantos años tienes? ")
   X = "BARRANQUILLA"
   MsgBox (" YANDRY VANESA BERRIO GOMEZ " & A & " AÑOS Y VIVE EN  " & X)
   
End Sub


## 2. ejercicio_de_DartPad

void main() {
  String a = "21" ; 
  print ( " YANDRY GOMEZ TIENE " +  a +  " años ");
}

## 3. ejercicio_de_java

public class Main {
    public static void main(String[] args) {
        String a = "21";
        System.out.println(" YANDRY GOMEZ TIENE " + a + " años ");
    }
}
