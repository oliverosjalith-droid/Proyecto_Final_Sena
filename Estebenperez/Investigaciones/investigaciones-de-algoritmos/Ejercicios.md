# ejercicios de la seccion 10/09/2026
## ejercicio de excel
Sub PROGRAMA()

     a = 18
     MsgBox "Esteben tiene " & a & " años"
 
End Sub
### explicacion del algoritmo
este algoritmo sirve para almacenar una edad en una variable y mostrarla posteriormente en un mensaje emergente de Excel.

## ejercicio de dartpad
void main() {
  
    String a = "18";
    print("Esteben tiene $a años"); 
  
}
 

### explicacion del algoritmo 
este algoritmo sirve para guardar la edad de Esteben en una variable de texto y después mostrarla junto con un mensaje en la consola

## ejercicio en javascript

public class Main {
    public static void main(String[] args) {
        
        String a = "18";
        System.out.println("Esteben tiene " + a + " años");
        
    }
}

La diferencia principal es que en Dart usas print("Esteben tiene $a años"), mientras que en Java utilizas System.out.println("Esteben tiene " + a + " años").
