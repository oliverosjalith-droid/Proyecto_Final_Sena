# JavaScript

## ¿Qué es?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas y dinámicas. Permite que una página responda a las acciones del usuario, como hacer clic en botones, llenar formularios o mostrar información.

## ¿Cómo funciona?

JavaScript se ejecuta principalmente en los navegadores mediante un motor de JavaScript. El navegador procesa las instrucciones y realiza las acciones indicadas por el programa.

Por ejemplo:

```javascript
let nombre = "Ana";

console.log("Hola " + nombre);
```

El programa guarda el nombre en una variable y después muestra un saludo en la consola.

## ¿Para qué sirve?

JavaScript sirve para:

* Crear páginas web interactivas.
* Crear botones, menús y animaciones.
* Validar formularios.
* Desarrollar aplicaciones web.
* Trabajar con servidores mediante tecnologías como Node.js.

## Importancia

JavaScript es uno de los lenguajes más importantes del desarrollo web porque permite agregar interacción y comportamiento a las páginas. Junto con HTML y CSS, forma parte de las principales tecnologías utilizadas para crear sitios web.
