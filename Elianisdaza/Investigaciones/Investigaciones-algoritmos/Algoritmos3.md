# ALGORITMOS MIENTRAS 

Los ejercicios con el comando mientras en PSeInt son prácticas de programación que usan un bucle para repetir un bloque de código de forma indefinida hasta que una condición deja de cumplirse.

## Cómo funciona el ciclo Mientras

El ciclo evalúa una condición al principio de cada paso. Si es verdadera, las instrucciones internas se ejecutan. Si es falsa desde el inicio, el bloque no se ejecuta nunca.

# ALGORITMOS REPETIR

El comando Repetir (también conocido como Repetir-Hasta Que) en PSeInt es una estructura de control repetitiva que ejecuta un bloque de instrucciones primero y luego evalúa una condición al final.Según la documentación de PSeInt en SourceForge, el ciclo continuará repitiéndose mientras la condición sea falsa. El bucle se detiene inmediatamente en el momento en que la condición se vuelve verdadera.
