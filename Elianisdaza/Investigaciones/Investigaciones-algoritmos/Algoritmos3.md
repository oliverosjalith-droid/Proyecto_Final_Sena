# ALGORITMOS MIENTRAS 

Los ejercicios con el comando mientras en PSeInt son prácticas de programación que usan un bucle para repetir un bloque de código de forma indefinida hasta que una condición deja de cumplirse.

## Cómo funciona el ciclo Mientras

El ciclo evalúa una condición al principio de cada paso. Si es verdadera, las instrucciones internas se ejecutan. Si es falsa desde el inicio, el bloque no se ejecuta nunca.
