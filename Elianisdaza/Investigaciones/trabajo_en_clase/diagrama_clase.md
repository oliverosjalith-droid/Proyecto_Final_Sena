# Diagrama de clases

Un diagrama de clases es una representación gráfica de la estructura de un sistema. Permite identificar las clases, sus atributos, métodos y las relaciones que existen entre ellas. Se utiliza para organizar y comprender cómo está diseñado un sistema antes de programarlo.
